## 一、方法（严格遵循约束）

| 环节 | 做法 |
|---|---|
| 图号定位 | **确定坐标**：三份 PDF 标题栏图号锚点完全一致，裁剪窗口 `x[1508,1600] y[978,1002]` pt（A1 横版 1683.78×1190.55）。 |
| 图号判定 | **严禁正则**：纯字符状态机 `looks_like_sheet_no()`——两个点分三段，前两段全数字，第三段 `P`+数字。碎片化文本按 y 行分组、x 升序重组（应对旧版把图号拆成倒序单字符）。OCR 仅保留可选接口（本机无 tesseract，未启用；因文本层已 100% 覆盖，无需 OCR）。 |
| 工程图范围 | 剔除标题栏区（`x>1300 且 y>930`）后的矢量线画（`get_drawings` 的线段/矩形/曲线）。 |
| 指纹 | 等价复用 EGtools `VectorGeomDiff.Fingerprint`：48×32 占据网格 + 线段采样 + 自身包围盒归一化 + L2；相似度 = 余弦点积。**纯矢量，与文字语言无关、不受缩放平移影响**。 |
| 判重阈值 | 余弦 ≥ 0.97 判为"重复（工程图相同）"；< 0.97 判为"工程图有改动"。自比对 = 1.0（已验证）。 |

## 五、深入矢量差异比对（逐图元，不只是指纹）

指纹只回答"是否相同"；要回答**具体哪里改了**，调用项目内核 `EGpdf2df` 做逐图元矢量比对（非重造算法）。

### 方法
- 工具：`vector_diff.py`（定点单图号）/ `summarize_full_diff.py`（全本一次比对后按图号汇总）。
- 比对内核：`EGpdf2df.exe`（项目自带），算法 = 几何标定（处理静默缩放/平移）+ 共线覆盖匹配 + 第三态变更识别（增/删/改）+ 区域聚类。**纯矢量**。
- 一次全本比对：旧版 → 新版，`-o full_diff.pdf --graphic-method vector`，耗时约 10 分钟，产出红色标注差异 PDF。
- 结果按图号归属：`diffs[].page` → 图号映射。

### 结果（旧版 vs 新版，全本）
- **168 页配对，120 个图号有差异，629 个图形差异区域 + 1805 处文字差异**。
- 图形差异最多的图号（区域数）：`P38`=35、`P37`=34、`P35`=30、`P23`=22、`P32`=22、`P01`=19、`P93`=19、`P150`=18、`P36`=17、`P31`=14；`P21`=11、`P12`=11、`P15`=10。
- 与指纹粗筛交叉验证一致：指纹判"改动最大"的 P21/P23/P12/P15，矢量比对均报出 10~22 个图形差异区域。
- 标注 PDF（40MB，不入库）：`C:/Users/QBZ95/Desktop/tools/tz/_probe/full_diff.pdf`；汇总 JSON：同目录 `full_summary2.json`。

### ⚠️ 两个页索引陷阱（实测踩坑，务必遵守）
1. **不能用 `pin` 模式**：`--page-mode pin` 是按索引把页序钉死（给 p 就比 基准p↔目标p）。旧版/新版同图号**页码错开**（P21 旧=23 新=24），pin 会配成 基准24↔目标24（图号对不上）。必须用**默认 filter 模式**（先按真图号全本配对，再筛页）。
2. **`diffs[].page` 是目标侧 0-based 页索引**，不是基准页。曾误用基准页映射，把 P21（基准23/目标24）的 11 处差异归到基准24 的 P22。汇总必须用**目标 PDF** 建图号映射。

## 六、边界说明
- 指纹是**几何占据网格**，对"同布局不同数据"的图可能给出较高相似度；因此只在**同一图号**内比对，语义明确。指纹用于**快速筛查**哪些图号值得深挖，**权威结论以内核逐图元比对为准**。
- 剔除标题栏是为让指纹只反映工程图；语言差异（en/中文）不影响结论。
- OCR 辅助接口已留（`extract_from_pdf(use_ocr=True)` 启用），本机未装 tesseract 故未用；文本层已 100% 覆盖，OCR 非必需。
