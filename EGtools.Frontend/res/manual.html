EGtools 使用说明书

工程图纸材料表提取与对比工具集 · 面向 CAD 等轴测（isometric）PDF 图纸与管道材料表（Excel）。
版权 © 2026 HerryABU · 许可证 AGPL-3.0

三层架构。本 Qt 应用只是交互壳：负责显示页面、框选、坐标转换与流程编排；所有 PDF / Excel 的实际处理都由独立的 .NET 命令行内核完成，前后端通过 JSON / 文件契约通信。这样内核可独立批量使用，界面也可单独替换。

1. 界面总览

区域说明
顶部工具栏打开 PDF、翻页、重渲染、三种框选模式切换、导出 JSON、提取、图纸差异、清空框选。
左侧画布显示当前页（由内核栅格化）。在画布上按住左键拖拽即可画橡皮筋矩形。
右侧面板四个标签页：表格结果、管线号、区域 JSON、内核日志。
CLI 目录指定存放 EGpdf2excel.exe / EGpdf2df.exe 的目录（下方说明）。

2. 配置 CLI 内核目录

界面本身不含 PDF 逻辑，需告诉它内核 exe 在哪：

  • 在右侧「CLI 目录」输入框填入目录，或点「…」浏览选择；
  • 该目录应同时包含 EGpdf2excel.exe 与 EGpdf2df.exe（一般即 DIST/EGpdf2excel 与 DIST/EGpdf2df 的上级共同位置，或把它们放同一目录）；
  • 也可在启动前设置环境变量 EGTOOLS_CLI_DIR，或用命令行 --cli-dir <目录>。
若目录无效，内核日志会提示「无法启动 / 找不到文件」，请检查路径。

3. 打开 PDF 与翻页

  1. 点「打开 PDF」选择一个等轴测图纸 PDF。
  2. 应用会调用内核 --render 把第 1 页栅格化为图像显示，并自动探测总页数。
  3. 用「上一页 / 下一页」翻页；切换页会重新栅格化该页。

4. 三种框选模式（核心）

在顶部「框选模式」下拉里选择语义，然后在画布上拖拽出矩形。矩形会按 PDF 点（左上原点、y 向下） 记录。三种模式：

模式内部 kind用途
全域表global_table框住整张材料表，抽取全部行×列。
细表detail_table框住某个子表 / 明细块，只抽取该块。
材料编号区material_no_region框住图纸中管道/管线编号所在区域，抽取编号列表。

可在同一页做多个框选；同页同类型的框选在送入内核前会按并集合并成一个区域。

5. 导出区域 JSON（交给内核的契约）

点「导出 JSON」把当前所有框选写成 RegionRequest 并存盘，可直接喂给内核。格式：

{
  "pdf": "C:/docs/drawing.pdf",
  "pages": [0],
  "regions": [
    { "page": 0, "kind": "global_table",       "bbox": {"x":80,"y":60,"width":300,"height":220} },
    { "page": 0, "kind": "material_no_region", "bbox": {"x":40,"y":40,"width":400,"height":60} }
  ],
  "options": { "ocrFallback": true, "mergeOverlapping": true }
}
坐标约定（左上原点、y 向下、单位 PDF 点）。像素→点的换算为 pt = px / renderScale，renderScale 由内核下发，不硬编码任何图纸坐标。因此换一台电脑、换 DPI、换图纸都无需改代码。

6. 提取（调用内核）

  1. 框选完成后点「提取 (内核)」。
  2. 应用把框选组装成 JSON 交给 EGpdf2excel --mode region，解析返回结果。
  3. 结果分栏展示：表格结果进「表格结果」页，管线号进「管线号」页；抽取到的字框会回叠到画布（红框），便于核对；完整 JSON 见「区域 JSON」页。

内核矢量文本优先；仅当区域没有可用矢量文字时，才用 MuPDF 内置 Tesseract OCR（专业 OCR 库，不是 Windows 系统 OCR）兜底，此时内核日志会提示。表格分列由字形几何自动涌现，无任何硬编码列坐标。

8. 图纸差异（红标注）

  1. 点「图纸差异」，依次选择基准图与目标图。
  2. 应用调用 EGpdf2df 生成带红色差异标注的 diff.pdf，并在画布中预览。

差异分两步、独立处理：① 图形/图元差异——先按文字包围盒涂白排除文字区，避免文字微调被误报为图形变化，再做边缘/像素比对；② 文字/注释差异——独立于像素对比，识别增/删/改/移动。参数由内核 config.json 驱动。

7. 框选方案（复用 / 修改 / 存储 / 导出）

常用的框选可以存成方案，反复复用。点工具栏「框选方案」或首页「管理框选方案」进入二级页面。

能力怎么用
存储在画布框选后点「存为方案」；或进方案页「从当前框选存入」。方案自动持久化到 Documents\EGtools\schemes.json，重启不丢（写入用原子替换，不会写坏文件）。
修改字段直接在表格里改「类型 / 页 / X / Y / 宽 / 高」——类型是下拉、其余是可编辑单元格。不需要（也没有）JSON 编辑器。改完自动保存。
重写框选选中某行 → 点「重写框选」→ 回到画布拖拽重画一次 → 自动写回该行并存盘。
复用点「复用到画布」，该方案的所有框选立刻载入当前图纸，可直接点「提取 (内核)」。换一张图纸也能用——框选以 PDF 点存储，与分辨率无关。
导出 / 导入「导出 JSON」写出 RegionRequest 结构（regions[] 与内核契约完全一致，换个 PDF 路径即可直接 --json 交给内核）；「导入 JSON」可吃回同类文件。
坐标单位为 PDF 点、左上原点、y 向下——与内核和渲染图像同一约定，因此方案在不同 DPI/缩放下都成立。

9. 常见问题

现象处理
提示找不到内核 / 无法启动检查「CLI 目录」是否指向含 EGpdf2excel.exe/EGpdf2df.exe 的目录。
表格只抽到一列 / 列并在一起真实材料表列间距较大才分得开；请把框选放宽、把整表都框进去。
某区域内容为空该区域可能是扫描图（无矢量文字），会走 OCR 兜底；或框选偏了，请对齐表格区域。
翻页/渲染慢整页栅格化按需渲染；超大图纸可只处理目标页。

10. 命令行内核（可脱离界面批量使用）

# 整页材料表抽取
EGpdf2excel drawing.pdf -f xlsx

# 页面栅格化渲染
EGpdf2excel --render --page 0 --scale 2 --render-out page0.bmp drawing.pdf

# 区域框选提取
EGpdf2excel --mode region --json request.json

# 两份 Excel 图纸对比
EGexcel2df old.xlsx new.xlsx -o changes.xlsx

# 两份 PDF 图纸差异
EGpdf2df baseline.pdf target.pdf -o diff.pdf

11. 快捷键与自检

  • --test-math：坐标映射自检（无副作用，可在命令行验证换算正确）。
  • --selftest --pdf <文件>：渲染→换算→抽取全链路自检。
  • 命令行 --cli-dir <目录>：指定内核目录。
